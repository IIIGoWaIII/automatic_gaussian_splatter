# Automatic Gaussian Splatter

A streamlined, web-based interface for generating high-quality 3D Gaussian Splats from images or videos. This tool integrates **COLMAP** for sparse reconstruction, **Brush** for optimized training, **2DGS** for normal-aware surface reconstruction, and **Apple's ML-Sharp** for single-image 3DGS generation. All the links are generated by AI. Check if they are the correct ones.

### LiDAR Capture (ZIP) Workflow
Drop a SplatKing-style LiDAR capture `.zip` (e.g. `LidarSeries_*.zip`) into the WebUI and it runs a dedicated pipeline:
1. Extracts the archive and stages the capture images.
2. Converts the shipped COLMAP text model (device-tracked poses + fused LiDAR point cloud) to binary.
3. **Pose refinement** (recommended, on by default): SIFT feature extraction + sequential matching, then COLMAP point triangulation with global bundle adjustment — poses stay anchored to the device tracking but are refined against real image observations.
4. Trains the Gaussian Splat with Brush, LichtFeld-Studio, or 2DGS. When 2DGS is selected, the fused LiDAR cloud is projected into every training view to generate sparse depth supervision maps (`lidar_depth/`), and 2DGS trains with an additional LiDAR depth loss for geometrically accurate surfaces.

If refinement fails for any reason, the pipeline automatically falls back to the raw device-pose model.

## 🚀 Quick Start

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/IIIGoWaIII/automatic_gaussian_splatter.git
    cd automatic_gaussian_splatter
    ```
2.  **Start the WebUI**:
    Run the following batch file to set up the virtual environment and start the server:
    ```bash
    .\python_webui\run_app.bat
    ```
3.  **Install Components**:
    Once the WebUI opens (usually at `http://127.0.0.1:8000`), go to the **Updates** section to download and install:
    - **COLMAP** (Windows CUDA binaries)
    - **Brush** (Windows binaries)
    - **ML-Sharp** (Requires Python 3.13)

## 🛠️ Components

### 1. COLMAP
Handles the initial sparse reconstruction (Structure-from-Motion) from your image datasets or video frames. The app automatically manages the download of pre-built Windows CUDA binaries.

### 2. Brush
A high-performance Gaussian Splatting trainer. It features a real-time viewer and supports training from scratch or resuming from previous checkpoints.

### 3. ML-Sharp (Single Image 3DGS)
Incorporates Apple's ML-Sharp model to generate 3D Gaussian Splats from a single image. This requires a significant download (~2GB dependencies + ~500MB model checkpoint) which is handled by the built-in update manager.

### 4. 2DGS (2D Gaussian Splatting with Normals)
A Python-based trainer ([hbb1/2d-gaussian-splatting](https://github.com/hbb1/2d-gaussian-splatting)) that represents surfaces as oriented 2D disks, producing geometrically accurate normals — ideal for objects and surface reconstruction. Select **2DGS** in the Trainer dropdown. Requirements (bundled in `2d-gaussian-splatting-main/.venv`):
- PyTorch with CUDA + compiled `simple-knn` and `diff-surfel-rasterization` extensions
- MSVC Build Tools and a CUDA toolkit are needed if the extensions ever need to be rebuilt
- Training runs at `2d-gaussian-splatting-main/train.py`; checkpoints (`chkpnt*.pth`) are saved every 7000 steps so training can be resumed from the Resume tab
- A SIBR-compatible viewer socket is exposed on port `6009` during training (connect e.g. [GS_Monitor](https://github.com/RongLiu-Leo/Gaussian-Splatting-Monitor))
- LiDAR ZIP projects additionally get depth supervision: the fused LiDAR cloud is projected into each view (`lidar_depth/*.npz`, debug `_overlay.jpg` previews included) and used as an extra L1 depth loss during training
- Finished 2DGS runs are auto-converted to a standard 3DGS-compatible PLY (`model/export_<iter>.ply`), so results open directly in Brush, LichtFeld-Studio, SuperSplat, and other splat viewers

## 📁 Project Structure

- `python_webui/`: Core FastAPI server and Web interface.
- `ml-sharp/`: Local installation of the ML-Sharp component.
- `colmap-x64-windows-cuda/`: Managed COLMAP installation.
- `brush-app-x86_64-pc-windows-msvc/`: Managed Brush installation.
- `processing_output/`: Default location for all your 3DGS projects.

## 🤝 Troubleshooting

- **SSL Errors**: If ML-Sharp fails to download the model checkpoint due to SSL issues, the app includes a fallback mechanism to bypass verification.
- **Python Not Found**: Ensure Python 3.13 is in your system PATH or use the `py` launcher if available.
